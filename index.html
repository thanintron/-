รูปภาพใบเสร็จ

วิธีติดตั้งแอปลงบนหน้าจอมือถือ

ระบบนี้ออกแบบให้ใช้งานแบบ Web App บนมือถือ สามารถเพิ่มไว้ที่หน้าจอหลัก (Home Screen) เพื่อเปิดใช้งานและถ่ายใบเสร็จได้ทันทีเหมือนแอปทั่วไป:

สำหรับ iOS (iPhone / Safari)
  1. เปิดหน้าเว็บนี้ในเบราว์เซอร์ Safari
  2. แตะปุ่ม แชร์ (Share) ด้านล่างหน้าจอ
  3. เลือกเมนู "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)
สำหรับ Android (Chrome)
  1. เปิดในเบราว์เซอร์ Chrome บนมือถือ
  2. แตะเมนูจุด 3 จุด มุมขวาบน
  3. เลือก "เพิ่มลงในหน้าจอหลัก" (Add to Home screen / Install app)
